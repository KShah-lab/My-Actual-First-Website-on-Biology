# A website on Biology
#### My website gives an overview for some very important topics about biology such as Photosynthesis, Osmosis, and water. I intend to use this website as a learning platform for school where I write down everything that I learn in a lesson. For example, I learn about respiration and write down a topic on section about it. This way I not only learn html but also some really cool biology information at the same time. 
#### Here is the link to my website: https://kshah-lab.github.io/My-Actual-First-Website-on-Biology/
